# [종합설계프로젝트1] 회의록

---
    
- 2차 회의 (26.09.14 월 14:00 ~)
    - 질문 주제
        1. MVP로 구현한 우리 프로젝트를 논문/특허/공모전 출품 중 어떤 것이 가능한지
            - 답변: 기본적으로는 논문을 작성하긴 함.
        2. 임의로 정한 기술 스택에 대한 의견 여쭤보기
            - 답변: 일단 받아온 데모 파일을 기반으로 정하고 정해지면 구글 스페이스에 정하기
        3. API 키는 회사 내 자체적인 API 키를 제공하는지, 혹은 저희가 따로 부담하는 형식인건지
            - 답변: 일단 회사 전산팀에게 질문 후 다시 답변 주신다고 하셨음.
    - 질의에 대해서도 말로도 질문할 수 있어야 함 → 응답/질의 모두 멀티모달 형식
    
    → 전체적인 데모 파일은 구글 스페이스를 통해 멘토님께서 공유해주심. 이를 기반으로 음성인식 + 디자인 개선 + 데이터베이스 연동까지 되는 MVP의 느낌보다 발전된 완성품을 만드는 것이 이번 과제의 가장 큰 목표
