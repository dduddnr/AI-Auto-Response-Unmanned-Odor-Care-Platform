  # 데이터 스키마

  ## documents (문서 메타데이터)

|컬럼명|데이터 타입|제약조건 / 기본값|설명|
|-|-|-|-|
|doc\_id|UUID|PK, DEFAULT gen\_random\_uuid()||
|NOT NULL|문서 고유 식별자|||
|title|TEXT||문서 제목|
|source\_type|TEXT||출처 유형 (법령 / 공공데이터 / 센서 / 논문 / 내부지식), 목업이면 임의 배정|
|evidence\_tier|INT||근거 계층 (1\~5)|
|source\_url|TEXT||원문 URL|
|published\_at|DATE||기준시점 (발행·공포일)|
|collected\_at|TIMESTAMP|DEFAULT now()|수집 일시|
|license\_note|TEXT||라이선스·이용조건 메모|
